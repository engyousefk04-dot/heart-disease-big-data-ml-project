# Heart Disease Prediction Using Big Data and Machine Learning

## Project Overview
This project applies data analysis, Big Data concepts, and machine learning techniques to predict whether a person has heart disease or not.

## Dataset
We used the Heart Disease dataset from Kaggle. The dataset contains medical features such as age, sex, chest pain type, cholesterol, blood pressure, maximum heart rate, and target.

## Objective
The objective is to build a machine learning model that predicts heart disease.

## Data Analysis
We performed:
- Data loading
- Missing values checking
- Duplicate removal
- Exploratory Data Analysis
- Filtering
- Grouping
- Aggregation
- Insight extraction

## Big Data Processing
We used PySpark DataFrames to apply:
- Schema inspection
- Filtering
- Grouping
- Aggregation

## Machine Learning Models
We trained multiple models:
- Logistic Regression
- KNN
- SVM
- Decision Tree
- Random Forest
- Gradient Boosting

## Model Evaluation
We evaluated the models using:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix
